# Telegram-бот для поиска музыки

Работает в личке, группах и супергруппах.

## Источники

Полные треки:
- **Audius** — независимые исполнители, электроника, хип-хоп
- **Jamendo** — музыка под лицензиями Creative Commons
- **Internet Archive** — свободные и архивные записи
- **ccMixter** — ремиксы и семплы под Creative Commons
- **Openverse** — открытое аудио из нескольких каталогов (только mp3, категория «музыка»).
  Необязательно: бесплатные ключи с https://openverse.org/ → `OPENVERSE_CLIENT_ID`
  и `OPENVERSE_CLIENT_SECRET` в `.env` повышают лимиты запросов.

Названия источников пользователям не показываются: в выдаче видны только треки.
Выдача чередует источники и убирает одинаковые треки из разных каталогов.

## Запуск

1. Создайте бота в @BotFather, скопируйте токен.
2. Получите `client_id` на https://devportal.jamendo.com.
3. `cp .env.example .env` и заполните `BOT_TOKEN`, `OWNER_ID`, `JAMENDO_CLIENT_ID`.
4. Установка и старт:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 bot.py
```

## Как пользоваться

- **Личка:** просто напишите название трека.
- **Группы/супергруппы:** `/music название` (также `/search`, `/m`).
- Каждый трек в выдаче — отдельная кнопка («время | название — исполнитель»): нажмите, и бот пришлёт аудио. Кнопки ‹ › листают страницы (по 8 треков).

## Реклама и роли

- `/admin` (только в личке, владелец и менеджеры): текст, кнопка, ссылка, вкл/выкл, предпросмотр.
- Только владелец: `/addmanager ID`, `/delmanager ID`.

## Структура

- `bot.py` — поиск, выдача, отправка аудио
- `admin.py` — панель рекламы и менеджеры
- `providers.py` — все источники музыки
- `db.py` — SQLite (менеджеры, реклама)
- `config.py` — настройки

## Важно перед монетизацией

- **Лицензии:** у многих треков Jamendo и ccMixter лицензии `NC` (non-commercial). Для проекта с рекламой нужно либо фильтровать такие треки, либо договариваться с правообладателями.
- **Условия API:** проверьте условия использования Jamendo и Audius для коммерческих проектов.
- **Реклама в РФ:** требуется маркировка (токен ERID через ОРД).

## Идеи на потом

Inline-режим (`@бот название`), фильтр по лицензиям, избранное и плейлисты, статистика запросов, кеш `file_id`, партнёрские ссылки на покупку треков.
